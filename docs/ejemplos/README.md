# Ejemplos de registros

Un registro completo por colección, en la forma en que lo escribe el investigador en `inbox/` (lista de registros, campos con `_` que `pnpm promover` quita, sin `tier` ni `procedencia`). Están recortados de registros publicados reales. Sirven para saber la forma; las reglas de cada colección están en `docs/colecciones/`, y el esquema que valida es el de `src/schemas/`, que no hace falta leer.
